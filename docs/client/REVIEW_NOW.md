# 现在开始看页面

> 用途：当你准备正式看这一版客户端页面时，直接按这份顺序看。
> 目标：先看门面，再看主链路，再看支撑页，避免来回跳着看。
> 当前默认工作室入口已切到 `/studio`，`/workbench` 仅保留兼容跳转。

## 一、先看这 5 个页面

按这个顺序打开：

1. `/home`
2. `/studio`
3. `/design/text-to-style`
4. `/shoot/marketing-variants`
5. `/toolbox/upscale`

这 5 个页面最能代表当前版本的整体状态。

---

## 二、每个页面你重点看什么

### 1. `/home`

重点看：

- 第一眼是否已经像正式产品首页
- Hero 是否有大片感
- 首页是否还是“字太多”
- 智能体工作台是否更像工作室入口
- 首页有没有让你想继续点进去

### 2. `/studio`

重点看：

- 是否像真正的工作台，而不是普通承接页
- 推荐路径是否一眼能看懂
- 白板项目和快捷动作是否自然
- 页面是否已经有“业务编排台”的感觉

### 3. `/design/text-to-style`

重点看：

- 研发设计这条线的气质是否成立
- 页面是不是像案例驱动工作台
- 左侧提交区、右侧结果区是否清楚
- 是否有“先做什么、下一步去哪”的感觉

### 4. `/shoot/marketing-variants`

重点看：

- 商拍页是否和研发设计页明显不同
- 是否更像营销素材工作台
- 页面是否有商拍、套图、投放的感觉

### 5. `/toolbox/upscale`

重点看：

- 工具箱页是否不再像后台工具页
- 是否更像交付增强工作台
- 与研发设计 / 商拍页是否有明显区分

---

## 三、看完这 5 个页面后，再看这 4 个支撑页

按这个顺序：

1. `/tasks`
2. `/assets`
3. `/wallet`
4. `/projects/board-01`

### 这 4 个页面你主要看：

- 还像不像后台页
- 列表、卡片、图片区是否已经顺眼
- 是否能支撑前面那些主页面形成闭环
