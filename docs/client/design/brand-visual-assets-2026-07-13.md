# AI创品品牌视觉与配图基线（2026-07-13）

## 1. 品牌主张

- 品牌名：**AI创品**
- Slogan：**有品，必不同。**
- 用户价值：不是替用户换一个花色，而是把故事、审美和态度做成别人复制不了的产品。
- 视觉原则：**克制的产品质感，承载张扬的个人表达。** 页面本身保持清晰、可靠；个性由图案、产品和真实使用场景表达。

## 2. 首批主题资产

| 代码资产 | 场景 | 页面用途 | 构图要求 |
| --- | --- | --- | --- |
| `/brand/generated/hero-expression.jpg` | 个性表达总览 | 首页首屏 | 1536x864，左侧留文案空间，右侧展示同品类不同表达 |
| `/brand/generated/family-expression.jpg` | 家庭纪念 | 首页故事卡 | 1536x1024，原始手绘与成品同时出现 |
| `/brand/generated/city-expression.jpg` | 城市文旅 | 首页故事卡、登录页 | 1536x1024，城市文化元素转译为现代产品设计 |
| `/brand/generated/business-expression.jpg` | 企业伴手礼 | 首页故事卡、页尾行动区 | 1536x1024，杯子、包装与品牌气质统一 |

首批资产均通过中台 Image2 能力生成，再落入自有 OSS 和客户端静态发布目录。业务客户端不得持有厂商密钥，也不得直接调用第三方图片接口。

## 3. 能力路径

```text
品牌/业务需求
  -> 中台 ability: packy_gpt_image_2_generate
  -> Image2 生成
  -> 中台媒资沉淀到自有 OSS
  -> 人工检查产品结构、图案一致性和构图
  -> 客户端发布目录
```

页面配图只是 Image2 的第一个内部真实用例。后续首页活动图、主题站头图、灵感专题和运营物料继续复用同一能力，不在业务端复制一套生成逻辑。

## 4. 配图门禁

每张对外图片发布前必须同时通过以下检查：

1. 产品结构可信：杯盖、杯把、吸管、包装不能出现明显错位或多余结构。
2. 主题匹配：图片必须能够回答“什么人有品、为什么不同、平台把什么做成了产品”。
3. 图案一致：同一画面内的原始素材、杯身图案和包装图案需要属于同一视觉体系。
4. 版位匹配：按实际页面槽位生成或裁切，不拉伸，不用低清图填满大画幅。
5. 文案安全：生成图片默认不包含可读文字、商标和水印，文字由页面真实 DOM 承载。
6. 双端检查：首页首屏、故事卡和登录页至少检查 1440px 桌面端与 390px 移动端，无裁切错误、文字遮挡和操作区溢出。

## 5. 后续待办

- 为多主题站建立主题配图 manifest，记录主题、场景、能力调用、生成版本和审核状态。
- 在运营后台增加主题资产表格和上下架能力，避免管理员直接进入 OSS 操作。
- 对产品列表图继续执行“产品实物图与设计图案一致”门禁，不能用品牌氛围图代替真实商品证据。
