# 首页商品视觉真实性准则

> 生效日期：2026-07-13  
> 适用范围：`podi-client-web` 首页、商品列表、活动页和品牌宣传图。

## 1. 核心规则

首页的价值主张是“AI创品，有品，必不同”，但表达个性不能牺牲商品真实性。

所有出现在业务页面中的杯子必须同时满足：

1. 能对应到当前产品库中的 `templateId` 和规格。
2. 有完整生产设计面尺寸。
3. 有对应 3D 模型。
4. 目录静态渲染已经通过 `catalog-render-readiness.ts` 人工复核。
5. 点击图片后进入同一个 `templateId` 和规格的产品设计页。

任一条件不满足，不能作为“可设计、可试做”的商品出现在首页。

## 2. 图片生成边界

- Image 2 可以用于背景、环境、氛围和非商品主体的视觉增强。
- Image 2 不得擅自改变杯体结构、杯盖、把手、吸管、容量比例和配件组合。
- 需要展示具体商品时，优先使用 `/models/catalog-renders/` 下与模型同名的审核图。
- 如果需要生成生活方式效果图，必须先以审核图作为商品参考，并在上线前核对商品结构没有发生变化。

## 3. 代码门禁

首页与商品列表统一通过 `src/data/catalog-product-visuals.ts` 获取：

- 可下单商品列表
- 模型文件
- 审核后的目录渲染图
- 首个可生产设计面

禁止再使用“按数组序号轮换图片”或“多个不同商品共用一张杯子图片”的实现。

## 4. 文案与可读性

- 首页首屏主标题固定承担品牌标语：`有品，必不同。`
- 价值主张必须位于首屏最高视觉层级，不能只放在眉题或页脚。
- 图片上的正文必须有稳定底色或高对比遮罩，不能依赖图片局部恰好较暗或较亮。
- 商品图片旁需保留模板号或可追溯商品名，方便运营和供应链核对。

## 5. 发布前检查

1. 首页每张杯子图片逐一核对模板号、规格和模型。
2. 点击每张商品图，确认进入相同商品的设计页。
3. 桌面端和移动端检查主标题、正文、按钮没有被商品图遮挡。
4. 检查所有文字在最亮和最暗图片区域仍可读。
5. 扫描页面，确认没有未在售马克杯、缺尺寸产品和未审核模型。
