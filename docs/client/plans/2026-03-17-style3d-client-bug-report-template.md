# 客户端问题反馈模板（执行版）

> 用途：后面你正式测这一版客户端时，发现问题就按这个格式记。
> 目标：让我拿到问题后，不需要反复追问上下文。
> 文档状态：阶段测试包模板。
> 模板仍可继续使用，但是否现在进入正式问题回收流程，以最新测试通知为准。

## 单条问题模板

### 问题标题

- 页面：
- 功能：
- 测试账号：
- 操作步骤：
- 实际现象：
- 预期现象：
- 是否稳定复现：
- 出现频率：
- 是否影响业务：
- 是否阻塞后续测试：
- 建议优先级：

---

## 推荐标题写法

建议用这种格式：

- `[首页] 顶部搜索打开后结果为空`
- `[任务中心] 再来一次没有带回原参数`
- `[图案提取] 上传后提交按钮无响应`
- `[钱包] 充值单创建成功但状态无法刷新`

---

## 建议优先级口径

### P0

- 直接影响业务
- 完全不能用
- 会阻断后续测试

### P1

- 主流程可用，但明显不对
- 影响用户理解或反复操作

### P2

- 功能基本可用
- 但体验不顺、表现不稳定、细节不完整

### P3

- 纯视觉 / 文案 / 轻微交互问题
- 不影响继续测试

---

## 最后汇总时建议带上

- 通过项数量
- 失败项数量
- 阻塞项数量
- 最影响业务的 3 个问题
