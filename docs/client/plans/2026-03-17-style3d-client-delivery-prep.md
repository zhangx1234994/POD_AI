## 3. 你后面测试时优先看什么

### 第一组：首页 / 工作台观感

重点看：

- 首页第一屏是否已经有“客户端门面感”
- 工作台是否像承接页，而不是简单功能导航
- 高概率会点的按钮是否都能走通

### 第二组：任务与素材闭环

重点看：

- 任务中心列表是否清楚
- 查看结果 / 再来一次是否顺手
- 素材库里的继续创作是否自然

### 第三组：真实任务

重点看：

- 上传是否稳定
- 同步任务结果是否正常
- 异步任务是否能回填
- 失败 / 排队 / 处理中状态是否能理解

### 第四组：账户链路

重点看：

- 钱包页信息是否清晰
- 充值单创建和返回原页面是否顺
- 余额不足时的拦截是否符合直觉

---

## 3.1 建议测试顺序

如果你想一轮测下来更省时间，建议按这个顺序：

1. 首页 / 工作台 / 顶部搜索
2. AI研发设计
3. AI视觉商拍
4. AI工具箱
5. 任务中心
6. 我的素材
7. 钱包 / 充值回流
8. 项目详情页

这样测的好处是：

- 先确认门面和导航
- 再确认核心业务页
- 最后确认回流闭环

---

## 3.2 建议重点点位

### 首页

- 顶部搜索是否好用
- 首页第一屏是否已经像客户端首页
- 建议词 / 智能体 / 白板卡片是否都能点

### 工作台

- 智能体卡片是否能进对应页面
- 推荐路径是否清楚
- 是否像“承接页”而不是普通菜单页

### 任务中心

- 功能筛选是否有效
- 查看结果 / 再来一次是否顺
- 结果预览是否清楚

### 项目详情页

- 时间线是否能跳任务中心
- 项目素材是否能带着素材继续创作
