# 客户端版本更新说明

> 用途：给这次客户端测试版一个简洁更新摘要。  
> 场景：开始测试前，快速知道这一版重点改了什么。
> 文档状态：阶段测试包文档。
> 这里的“本版重点”对应 2026-03-17 当时的测试版，不代表当前最新客户端变化已经完全同步到本文。

## 本版重点

### 1. 客户端主结构成型

- 首页
- 工作台
- AI研发设计
- AI视觉商拍
- AI工具箱
- 任务中心
- 我的素材
- 钱包 / 充值
- 项目详情页

### 2. 高概率入口已基本收口

- 顶部搜索 -> 快捷入口面板
- 顶部搜索 -> 支持 `/` 与 `Cmd/Ctrl + K`
- 首页建议词 -> 对应功能
- 首页智能体 -> 对应功能
- 首页最近任务 -> 任务中心
- 工作台智能体 -> 对应功能
- 项目页时间线 / 素材 -> 可点击跳转
- 首页已补“团队角色区 / 支持与入口区 / 品牌底部信息区”
- 首页已继续补“专题橱窗 / 大图区 / 更强案例感”
- 工作台已继续补“故事板案例区 / 推荐起手案例大图”
- 模块页已继续补“模块统计块 / 高频动作块 / 能力信号卡”
- 具体功能页已继续补“提交信号卡 / 推荐路径区 / 结果看板”
- 三大模块已继续拆出各自业务气质和主线标签，不再只是共用壳
- 功能页已继续补“一键带入灵感 / 下一步推荐”，开始具备工作流引导感
- 高频能力页已继续补“功能专属起手灵感 / 功能专属下一步推荐”
- 高频页示例卡已继续补“案例标签 / 场景说明”，更接近案例板
- 任务中心 / 素材库 / 钱包页已继续补“摘要卡 / 场景卡”，减轻后台感
- 首页 Hero 与模块头图已继续补“胶片卡 / 案例轨道”，第一屏更有大片感
- 首页智能体工作台已继续补“可视化橱窗卡”，减少纯说明感
- 任务中心 / 素材库 / 钱包页的场景卡已继续补成带图版本，进一步减轻说明感
- 顶部条 / 底部状态条 / 项目详情页的语气和层次已继续统一
- 任务卡 / 素材卡 / 项目卡已继续补图片角标，识别性更强

### 3. 关键闭环已接通

- 上传 -> 提交 -> 结果回填
- 任务中心查看结果 / 再来一次
- 结果进入素材库
- 素材继续创作
- 积分不足 -> 钱包 -> 返回原页面

### 4. 稳定性补充

- 多图上传稳定性已补
- 异步任务字段归一化已补
- 过期登录态自动失效已补
- 演示态任务预览也可用

### 5. 自动化基线

- 本地 UI smoke：`18 / 18`
- 本地 `selfcheck:local`：通过
- 本地 `selfcheck:full`：通过
- 远端同步 / 异步样本：通过
