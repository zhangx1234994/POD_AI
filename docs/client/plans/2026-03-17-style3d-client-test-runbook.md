# 客户端集中测试执行清单（执行版）

> 用途：当正式开始测试这一版客户端时，直接按这份清单走。  
> 目标：一轮测试里尽量同时覆盖门面、真实链路、闭环和异常回流。  
> 建议：按顺序执行，不要跳着测。
> 文档状态：阶段测试包文档。
> 如果当前仍处在持续重构阶段，请先确认本轮是否已经重新开放正式测试，再按此清单执行。

## 1. 测试前准备

- [ ] 能打开客户端首页
- [ ] 能打开钱包页
- [ ] 测试图片已准备好
- [ ] 知道测试账号
- [ ] 后端已更新到当前版本

建议准备：

- 记录一个文档或表格
- 每发现一个问题，就记：
  - 页面
  - 功能
  - 现象
  - 是否能稳定复现
  - 是否影响业务

---

## 2. 第一轮：首页 / 工作台 / 顶部入口

### 首页

- [ ] 顶部搜索可打开
- [ ] 顶部搜索可搜到“图案提取”等入口
- [ ] 首页 Hero 第一屏观感正常
- [ ] 首页建议词按钮可点击
- [ ] 首页智能体卡片可点击
- [ ] 首页白板卡片可点击
- [ ] 首页最近任务卡片可点击

### 工作台

- [ ] 进入工作台页面正常
- [ ] 智能体卡片可进入对应页面
- [ ] 快捷动作卡片可进入对应页面
- [ ] 推荐路径表达是否清楚
- [ ] 页面整体是否像承接页

---

## 3. 第二轮：工具箱先测

优先测这 5 个：

- [ ] AI超清
- [ ] 无损放大
- [ ] AI扩图
- [ ] 高质量缩放
- [ ] DPI处理

每个都看：

- [ ] 页面能进入
- [ ] 图片能上传
- [ ] 参数能调整
- [ ] 能提交
- [ ] 结果区有反馈
- [ ] 任务中心有记录
- [ ] 素材库有沉淀

---

## 4. 第三轮：研发设计线

优先测这 6 个：

- [ ] 以文生款
- [ ] 以款生款
- [ ] 融合创款
- [ ] 图案提取
- [ ] 图案融合
- [ ] 四方连续

重点看：

- [ ] 页面结构是否清楚
- [ ] 多图上传是否稳定
- [ ] 异步任务回填是否正常
- [ ] 结果是否能回到任务中心
- [ ] 结果是否进素材库

---

## 5. 第四轮：视觉商拍线

优先测这 3 个：

- [ ] 裂变套图
- [ ] 图生视频
- [ ] 服装细节图

重点看：

- [ ] 页面是否清楚
- [ ] 提交是否顺
- [ ] 异步任务状态是否能理解
- [ ] 结果区是否有反馈

---

## 6. 第五轮：任务中心 / 素材库闭环

### 任务中心

- [ ] 全部 / 排队中 / 处理中 / 已完成 / 失败 切换正常
- [ ] 按功能筛选可用
- [ ] 结果预览弹窗可打开
- [ ] 查看结果可跳回工作台
- [ ] 再来一次可带回原图和参数

### 素材库

- [ ] 原图 / 结果图 / 视频 / 收藏 切换正常
- [ ] 素材下载正常
- [ ] 继续创作正常
- [ ] 删除素材正常
