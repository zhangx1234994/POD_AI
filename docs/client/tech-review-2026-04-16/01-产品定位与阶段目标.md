# 01. 产品定位与阶段目标

## 当前定位

客户端不再按“一个好看的 AI 出图网站”理解，而按下面这个定义统一：

**面向服装设计与电商运营团队的行业 SaaS 设计生产平台前台。**

它当前必须同时承担 4 件事：

1. 获客与转化
2. 生产与交付
3. 资产与复用
4. 商业与留存

## 当前阶段

当前不是做完整终局，而是在做 `Phase 1` 最小商用闭环。

第一阶段只要求打通这条主路径：

```text
首页理解价值
  -> 进入 Studio
  -> 选择高频工作流
  -> 发起首任务
  -> 回看结果
  -> 结果进入资产中心
  -> 继续创作 / 复跑 / 看余额
```

## 当前页面职责

### 首页

- 承担案例说服、试用导向、工作流说明、商业锚点

### Studio

- 承担“今天先做什么”的工作入口
- 承担最近任务、最近资产、模板入口、推荐路径
- 承担首轮经营看板

### 工作台

- 保留真实能力调用、轮询、结果回填、素材沉淀
- 表现层按产品叙事重构

### 任务中心

- 承担结果回看、失败解释、重做、继续创作

### 资产与模板中心

- 不再只是素材仓库
- 要把结果变成下一次创作入口

### 钱包页

- 承担余额感知、充值、低余额拦截回流

## 当前高频工作流边界

### 设计侧

- 以文生款
- 以款生款
- 图案提取
- 四方连续

### 运营侧

- 裂变套图
- 图生视频
- 细节图

### 工具侧

- AI 超清
- 高质量缩放
- DPI 处理

## 这一阶段不做什么

- 不把全部能力一次性铺满
- 不把对话式助手作为主入口
- 不先做复杂团队协作
- 不做第二条正式客户端主线

## 评审时建议重点看什么

1. 当前定位是否统一
2. 当前高频工作流边界是否认可
3. 当前主路径是否足够支撑第一阶段上线
4. 是否需要调整 `Phase 1` 的优先级
