# 02. 当前实现与代码主线

## 唯一代码主线

- 前端主线目录：`podi-client-web/`
- 不再把 `podi-client-v2/` 作为当前正式交付主线
- 当前所有产品化改造都落在 `podi-client-web/`

## 当前保留的真实运行时链路

下面这些不是静态页面，而是已经接到真实链路：

- 登录
- 能力清单读取
- 同步调用
- 异步任务创建
- 任务轮询
- 结果回填
- OSS 上传
- 素材沉淀
- 钱包余额读取
- 充值单创建 / 刷新

## 当前已经完成的前台产品化改造

### 首页

- 改成转化首页
- 强化案例、工作流、模板、商业锚点

### Studio

- 改成工作入口页
- 有最近任务、最近资产、模板入口、推荐路径
- 新增首轮经营看板

### 工作台

- 运行时和表现层开始拆开
- 模板可直接带入表单
- 素材和任务结果可带上下文回流

### 任务中心

- 支持结果预览
- 支持重做
- 支持继续创作
- 已从“纯状态页”转成“结果回看 + 回工作流入口”

### 资产与模板中心

- 支持筛选、下载、继续创作
- 模板可直接带入
- 素材回流开始按语义做智能分流

### 钱包页

- 支持低余额拦截回流
- 支持充值单创建 / 状态刷新
- 会根据差额推荐更适合的套餐

## 当前新增的关键前端能力层

### 表现层配置

- `podi-client-web/src/config/clientProduct.ts`
- `podi-client-web/src/config/toolPresentation.ts`

### 继续创作与上下文种子

- `podi-client-web/src/services/workspaceSeeds.ts`

### 经营埋点与看板汇总

- `podi-client-web/src/services/clientAnalytics.ts`

### 核心控制器

- `podi-client-web/src/hooks/useWorkspaceController.ts`

## 当前工程实现状态

- `npm run lint` 通过
- `npm run build` 通过
- `npm run test:ui` 通过

## 当前仍然属于“前端第一版”的部分

- 埋点现在已经有统一出口协议，但默认仍可只保留在本地
- 素材中心、任务中心的继续创作规则已开始智能化，但还不是完整行业规则引擎
- 资产沉淀仍以客户端本地沉淀为主，尚未完全升级到正式后端资产中心

## 当前建议技术负责人重点确认

1. 是否认可 `podi-client-web/` 作为唯一继续开发主线
2. 是否认可继续保持“运行时保留，表现层继续产品化”
3. 是否需要提前把本地资产沉淀升级为正式后端资产中心
