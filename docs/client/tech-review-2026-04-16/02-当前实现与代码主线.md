# 02. 当前实现与代码主线

> 历史说明：本文记录 2026-04-16 当时的客户端代码主线判断。当前仓库已不再包含客户端代码目录，文中 `podi-client-web/` 相关描述只作为历史审查资料。

## 唯一代码主线

- 前端主线目录：`podi-client-web/`
- 不再把 `podi-client-v2/` 作为当前正式交付主线
- 当前所有产品化改造都落在 `podi-client-web/`

## 当前保留的真实运行时链路

下面这些不是静态页面，而是已经接到真实链路：

- 登录
- 能力清单读取
- 同步调用
- 异步任务创建
- 任务轮询
- 结果回填
- OSS 上传
- 素材沉淀
- 钱包余额读取
- 充值单创建 / 刷新

## 当前已经完成的前台产品化改造

### 首页

- 改成转化首页
- 强化案例、工作流、模板、商业锚点

### Studio

- 改成工作入口页
- 有最近任务、最近资产、模板入口、推荐路径
- 新增首轮经营看板
- 继续补了白卡阅读层级和对比度，桌面态视觉走查下不再容易出现“卡片里像占位块”的阅读感
- 最新一轮又继续压缩了首屏表达：副文案缩短成“先发起首任务，再回看结果，再从资产继续创作”，三张优先卡的说明也同步收短，减少首次进入时的阅读成本

### 工作台

- 运行时和表现层开始拆开
- 模板可直接带入表单
- 素材和任务结果可带上下文回流
- 模块页、侧栏、工作台头部、上传区和提交区已经补一轮响应式稳定性收口，避免中等桌面宽度下布局失衡
- 已做一次截图级视觉走查，修复 `client-module-page` 错误占列导致主工作区宽度塌缩的问题，并提升工作台头部文案对比度
- 继续补了一轮前台可读性收口：任务/资产卡的操作入口更明确，钱包页洞察卡的版面节奏更稳定
- 最近一轮已把 `AI研发设计 / AI视觉商拍 / AI工具箱` 三条工作台的共用壳层继续统一，侧栏不再是高噪音彩色列表，表单区和结果区也已收成更稳定的浅底工作区
- 最新一轮又继续做减法：侧栏说明压缩成“先选一个动作”，结果区标题统一收成“结果区与下一步”，避免用户在开始提交前被过多解释文本打断

### 任务中心

- 支持结果预览
- 支持重做
- 支持继续创作
- 已从“纯状态页”转成“结果回看 + 回工作流入口”
- 任务行、结果预览、空状态已经开始统一使用“下一步动作 + 推荐原因 + 重做入口”的交互语言
- 未完成任务不再继续挂“结果”入口，交互语义已经改成“处理中等待回看 / 失败后直接重做”
- 最新一轮已把任务中心顶部改成显式动作区，用户进入页面后会先看到“先看处理中 / 先看已完成 / 先发起任务”这种主动作，而不是先被任务表格淹没
- 最新一轮又继续统一顺序：任务中心会先展示当前任务内容和下一步承接，再展示沉淀指标，不再把抽象指标摆在任务列表前面
- 最新一轮继续做减法：页头语言已压短成“先看处理中，再看结果，再决定继续还是重做”，并去掉页头右上角漂浮的重复入口，避免用户一进入页面就被两个相同层级的动作打断

### 资产与模板中心

- 支持筛选、下载、继续创作
- 模板可直接带入
- 素材回流开始按语义做智能分流
- Studio / Assets / ProjectDetail 现在会统一提示素材的推荐下一步，而不是只给一个模糊“继续”按钮
- 最新一轮已把资产中心顶部也收成“先筛素材类型 -> 再决定继续创作 / 下载 / 带模板复跑”的显式动作区，减少用户在素材卡堆里自己找下一步
- 最新一轮又继续统一顺序：资产中心会先展示手头素材，再展示沉淀价值和模板入口，不再把抽象说明压在具体内容前面
- 最新一轮继续压缩页头表达，改成更直接的“先筛素材类型，再决定继续创作”，并去掉页头右上角漂浮的重复入口，让首屏只保留真正的主动作

### 首页 / Studio 首屏动作

- 首页首屏三种开始方式已改成可点击动作卡：第一次来直接进 Studio，已有参考图直接进以款生款，只想修结果直接进 AI 超清
- Studio 首屏已从“工作入口 + 经营验证并列”收成“先做什么”优先，经营验证板块已下沉到页面后段，不再干扰首次使用
- 最新一轮又继续做减法：首页 Hero 已去掉一层重复摘要，Studio 首屏也去掉了重复动作层，只保留优先级更明确的主路径
- 首页和 Studio 的 section 顺序也开始统一成“先入口 / 当前动作 -> 再最近结果或模板 -> 最后再看抽象路径与经营信息”，减少用户切页时的心智切换
- 最新一轮视觉收口又继续压缩了首页 Hero：主标题尺寸已收小，动作卡前新增“现在直接开始”，右侧大图只保留少量必要状态标签，不再让概念表达压过起手动作

### 钱包页

- 支持低余额拦截回流
- 支持充值单创建 / 状态刷新
- 会根据差额推荐更适合的套餐
- 工作台会提前显示余额、预计消耗和差额，用户可直接从工作台先去充值
- 钱包页会保留原任务上下文，并把“当前工作流 / 当前余额 / 预计消耗 / 当前差额”放到同一层说明
- 最新一轮视觉走查已继续提升钱包 Hero 与摘要卡的对比度，用户更容易一眼看清“先看余额 / 再看差额 / 再选套餐”
- 最新一轮又把钱包页的主动作前置成显式入口：页头和 Hero 都能直接“先看充值套餐”或“回原任务继续提交 / 回工作室选下一步”，不再需要用户进入钱包后自己找下一步
- 最新一轮继续收口了钱包首屏顺序：页头语言压短成“先补足差额，再回原任务继续”，并把 Hero 提前到差额摘要卡之前，让用户先看到该做什么，再看支持信息

### 跨页一致性

- `Home / Studio / Tasks / Assets / Wallet` 现在已经开始统一成同一套动作语言：
  - 先看当前动作
  - 再看结果或素材
  - 最后才看抽象指标、模板价值或商业说明
- `Tasks / Assets / Wallet` 的主按钮命名和回流说明也已统一到“继续创作 / 回工作室选下一步 / 回原任务继续提交”这一层，不再每页各说各话
- 顶栏的跨页动作也已经同步收口：`任务中心 / 资产中心 / 钱包` 压缩成更短的单层标签，不再在顶栏里重复“回看 / 沉淀 / 套餐”这类二级解释

## 当前仍然属于“前端第一版”的部分

- 埋点现在已经有统一出口协议，但默认仍可只保留在本地
- 素材中心、任务中心的继续创作规则已开始智能化，并且会开始携带原始 prompt、推荐下一步名称和推荐原因，但还不是完整行业规则引擎
