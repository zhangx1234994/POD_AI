# 14. 设计交接清单

## 1. 用途

这份清单用于后续 Figma 低保真、高保真和前端开发对齐。

## 2. 设计前必须确认

- 是否以 `06-13` 文档作为当前结构真源
- 首页、单功能页、批量页是否为第一优先级
- 当前哪些入口保留，哪些降权

## 3. 每个页面必须补齐的状态

### 首页

- default
- loading
- empty
- error

### 单功能页

- default
- loading
- running
- success
- error
- empty history

### 批量页

- not started
- running
- completed
- failed items present

## 4. 每个页面必须明确的内容

- 标题与一句话说明
- 主 CTA
- 次级 CTA
- 轻提示
- 错误提示位置
- 空态文案

## 5. 交互稿必须标出的点

- 哪些字段是必填
- 哪些字段折叠
- 提交后按钮状态如何变化
- 结果区何时刷新
- 用户视线主路径是什么

## 6. 开发前建议确认

- 是否需要保持现有 URL 结构
- 是否保留当前 API 合约不变
- 哪些旧区块直接降权，哪些暂时保留

## 7. 本轮推荐输出顺序

1. 首页低保真
2. 单功能页低保真
3. 批量页低保真
4. 三页交互状态稿
5. 高保真视觉稿
