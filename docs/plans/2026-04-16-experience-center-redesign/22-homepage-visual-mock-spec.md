# 22. 首页视觉稿说明 V1

## 1. 页面目标

首页要让人一进来就觉得：

- 这里是一个清楚、顺手的功能体验台
- 不需要理解系统结构，也能很快开始

## 2. 视觉基调

首页整体要比功能页更轻。

建议：

- 背景使用浅中性灰
- 主内容卡片使用白底
- 分类卡和功能卡有清楚但克制的层级差异
- 颜色强调只给真正的主动作和当前选中项

首页不建议做成：

- 重运营看板
- 大 Hero 营销页
- 灰重后台风

## 3. 页面区块视觉建议

### A. 顶部轻头区

建议高度较短，目标是“快速建立认知”，不是视觉表演。

建议包含：

- 左侧：标题 + 副标题
- 右侧：两个轻动作按钮

样式建议：

- 标题清楚但不过大
- 副标题弱化
- 按钮简洁，不做大色块压屏

### B. 分类总览区

这是首页第一视觉中心。

建议样式：

- 5 张分类卡固定宽度网格
- 卡片白底、轻边框、轻阴影
- 当前 hover 时边框和标题色略增强

每张卡片层级：

1. 分类名
2. 场景一句话说明
3. 功能数量
4. 快捷功能入口

快捷功能入口建议做成：

- 文本按钮
- 或轻标签按钮

### C. 高频功能区

这是首页第二视觉中心。

建议样式：

- 比分类卡更精致一点
- 每张功能卡更强调“主动作”
- 功能卡内保留足够留白

功能卡层级：

1. 功能名
2. 一句话用途
3. 标签
4. 主 CTA

建议 CTA 颜色统一，不因不同功能变色。

### D. 轻提示区

建议做成 3 张横向轻提示卡。

样式建议：

- 背景轻微染色
- 文案简短
- 图标可选，但不要太抢戏

目的是降低用户首次进入的犹豫，而不是讲完整教程。

## 4. 页面节奏

建议节奏：

- 顶部轻
- 中段聚焦
- 底部辅助

也就是：

```text
轻头区
  -> 分类区（主）
  -> 高频功能区（次主）
  -> 轻提示区（辅助）
```

## 5. 视觉重点

首页要把这两件事做得很明显：

1. 当前有哪些功能可直接体验
2. 点哪里能最快进去

因此不建议让以下内容抢视觉：

- 历史记录
- 统计指标
- 系统说明
- 文档入口

## 6. 首页视觉稿验收标准

1. 第一眼就知道这里是“选功能”的地方
2. 分类比说明更醒目
3. 功能卡比提示更醒目
4. 全页视觉不沉重
5. 主按钮位置和风格统一
