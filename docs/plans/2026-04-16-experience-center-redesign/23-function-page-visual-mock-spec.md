# 23. 单功能页视觉稿说明 V1

## 1. 页面目标

单功能页的视觉目标是：

- 让输入区和结果区都足够清楚
- 让页面看起来像一个“正在工作的功能台”
- 让历史和文档退到后面

## 2. 视觉基调

单功能页应比首页更稳定、更有工作台气质。

建议：

- 页面整体分栏明确
- 左侧输入区更规整
- 右侧结果区更突出
- 底部轻量沉淀区明显降权

## 3. 页面区块视觉建议

### A. 顶部功能说明卡

建议作为页面开头一张较宽的说明卡。

样式建议：

- 白底
- 标题较强
- 适合 / 不适合信息用两列或轻标签分组

要点：

- 不做长文
- 不做复杂说明区块
- 不挤占主工作区高度

### B. 左栏输入区

输入区要看起来“稳”和“可操作”。

建议样式：

- 整块白卡
- 表单字段分组明显
- 上传区样式比普通输入框更突出
- 主按钮固定且明显

设计重点：

- 第一屏完成核心操作
- 不让用户到处找按钮

### C. 右栏结果区

结果区是页面最重要的视觉焦点之一。

建议样式：

- 同级白卡，但比输入区更有展示感
- 状态区固定在上
- 结果图区尽可能大
- 错误提示靠近结果图

建议结果判断提示做成一张小的辅助卡，嵌在结果区底部或侧边。

### D. 底部轻量沉淀区

建议样式：

- 轻卡片列表
- 单条信息压缩
- 评分和备注放在一条记录卡内

这里的视觉权重应明显低于上面的主工作区。

### E. 文档 / 更多历史入口

建议做成：

- 二级标签
- 折叠区
- 次按钮跳转

不要做成和主工作区一样重的内容块。

## 4. 视觉比例建议

建议整个页面重心放在：

- 左右双栏主工作区

即：

- 顶部说明卡高度短
- 中间输入 / 结果区高度大
- 底部沉淀区高度短

## 5. 视觉重点

单功能页必须保证：

1. 上传和开始按钮很好找
2. 结果图足够大
3. 成功 / 失败一眼可区分
4. 历史不会把页面拖长得太乱

## 6. 单功能页视觉稿验收标准

1. 第一屏内完成核心操作
2. 输入和结果有明确主次但都清楚
3. 结果图不是配角
4. 历史与文档明显降权
5. 页面整体像工具体验页，而不是表单说明页
