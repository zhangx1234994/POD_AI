# 24. 批量页视觉稿说明 V1

## 1. 页面目标

批量页的视觉目标是：

- 让“配置 -> 进度 -> 复核”三件事的节奏非常清楚
- 让结果复核真正成为核心视觉区
- 让排障信息后置

## 2. 视觉基调

批量页应更像“流程工作台”，而不是“任务监控台”。

建议：

- 配置区规整
- 进度区简洁明确
- 复核区大、直观、好操作
- 明细区收起来

## 3. 页面区块视觉建议

### A. 顶部说明区

建议很轻。

只保留：

- 页面标题
- 一句话说明

不要用长文规则压住页面。

### B. 配置区

建议作为第一张主卡。

样式建议：

- 大白卡
- 字段排布规整
- 上传区明显
- CTA 稳定

重点：

- 让用户很快配完一批

### C. 进度区

建议作为第二张主卡，但比配置区更摘要化。

建议内容以数字摘要和批次状态为主，不先展示长表格。

样式建议：

- 关键数字突出
- 失败数、未入库数用状态色点到为止
- 操作按钮放在右侧或卡片顶部

### D. 结果复核区

这是整个页面的主视觉中心。

建议：

- 原图 / 结果图的展示尺寸明显大于其他区块
- 满意 / 不满意操作直接贴近图片
- 不满意原因和备注跟当前图片强绑定

视觉上要让人觉得：

- 这里才是这页最重要的事

### E. 明细排查区

建议样式：

- 折叠
- 浅层
- 较弱视觉层级

作用是辅助，不是主内容。

## 4. 视觉比例建议

批量页的视觉重心建议放在：

1. 配置区
2. 结果复核区

进度区居中，明细区最后。

## 5. 视觉重点

批量页必须让用户一眼看懂：

1. 当前批次是否正常
2. 这一批最值得看的问题样本在哪里
3. 从哪里导出结果

## 6. 批量页视觉稿验收标准

1. 配置区不杂乱
2. 进度区能快速扫读
3. 结果复核区是页面主焦点
4. 明细区不会抢主视图
5. 整体更像“复核页”而不是“任务表页”
