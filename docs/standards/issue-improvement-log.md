1) **产品商业化配图默认路由和视频参数画像都没有前置定义**
- 范围：产品文案 / 产品视频 / 测评端 / 业务 API

- 状态：已完成本地整改；产品商业化专项测试、业务 OpenAPI 契约测试、测评端 lint/build 和本地页面 DOM 验证通过，待发布后线上真实链路复测。
