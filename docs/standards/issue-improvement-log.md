## 2026-03-04

1) **中台内页在 1024~1366 宽度区间不易操作**
- 范围：管理端 / Integration Dashboard（尤其 ComfyUI 管理）
- 现象：Header 操作区与内页按钮组在窄屏时挤压，部分操作需要横向滚动或难点击。
- 影响：运维操作路径变长，用户误判为“页面卡死/无响应”。
- 根因：固定宽度控件 + 多列布局在中等分辨率缺少断点策略。
- 改进：
  - Header 操作区改为可换行；
  - ComfyUI 顶部分组按钮允许换行并强化命名；
  - ComfyUI 二级导航改为“分类 + 模块”双下拉（含上一/下一模块），减少多排按钮噪音；
  - ComfyUI 模块路由写入 hash，刷新后保持同一模块，便于远程协作定位；
  - ComfyUI 增加“三段流程导览卡”，明确资源维护 -> 版本发布 -> 节点运维的标准顺序；
  - “同步发布”分类增加三步执行面板（带计数），用于判断是否可进入下一步；
  - 三步执行面板增加状态徽章（前置未满足/待处理/进行中/已完成），降低“误入下一步”概率；
  - “同步发布”操作条采用单主 CTA 动态策略，降低误触发与决策负担；
  - “同步发布”增加统一引导卡（进入条件/完成条件/失败后建议），避免前后台状态语义不一致；
  - 服务器对比步骤的“新增服务器 + 历史对齐”改为辅助面板按需展开，减少主工作区滚动；
  - 清单发布步骤的“修复任务回执”改为按需展开，默认聚焦清单发布主流程；
  - 任务下发步骤默认折叠监控/历史区，先聚焦创建动作，再按需展开排障；
  - 全局壳层在超窄屏进一步压缩（侧栏/头部/内容间距），减少可视区域浪费；
  - ComfyUI 模块工具条改为响应式分行布局，小屏不再因顶部间距导致控件错位；
  - 任务列表状态列名统一为“提交阶段/回调阶段/最终状态”；
  - 输出文案系统 V1 草案（任务状态/错误提示/空状态模板）并纳入 standards；
  - 新增高频错误码页面提示映射（首批 20 条），统一“错误码 + 建议动作”；
  - ComfyUI“任务下发”失败列接入错误码映射，优先显示可读文案并保留错误码；
  - 能力调用列表与详情错误提示同步接入同一映射，减少跨模块文案割裂；
  - 评测端运行记录与提示消息同步接入错误码映射，前后台错误语义保持一致；
  - 认证/计费从“概念草案”推进到“实施清单”（迁移顺序、接口顺序、发布门槛、回滚策略）；
  - 补齐认证/计费专项回归测试计划（发布门槛与幂等场景纳入必测）；
  - 补齐 ComfyUI 任务状态专项回归计划（提交/回调/最终三段状态 + 错误映射）；
  - 侧栏增加“收紧/展开”开关并持久化；
  - 固定宽度输入改为 `min(100%, Npx)`；
  - 1366 以下自动将多列表单列栈叠；
  - 统一内容滚动容器，避免截断。
- 状态：已完成（含 build + Playwright 走查）

- 范围：评测端 / LoRA 批量测试
