# 上下文清理与文档治理准则

## 1. 目标

减少上下文噪音，保证“人和系统只看核心真源”。

## 2. 核心真源范围

1. 战略：`docs/strategy/strategy-one-page-2026q2.md`
2. 待办：`docs/strategy/todo-master-2026q2.md`
3. 规范：`docs/standards/*.md`
4. 接口：`docs/api/modules/*.md`
5. 总索引：`docs/README.md`

## 3. 清理规则

1. 同主题文档出现 2 份以上时，必须指定 1 份为真源，其余转归档。
2. 归档文件放入 `docs/archive/YYYYMM/`。
3. 归档文件首行必须写：
- `状态: archived`
- `归档原因`
- `替代文档`

## 4. 写作规则

1. 每份文档必须有“最后更新日期”。
2. 每份执行文档必须有“验收标准”。
3. 非执行文档（背景分析）不得承载执行待办。

## 5. 变更流程

1. 先改真源文档
2. 再改索引文档
3. 最后做代码/功能改动

## 6. 每周回顾（固定动作）

1. 清理失效任务
2. 合并重复任务
3. 补充本周错误复盘
4. 更新下周优先级

*最后更新: 2026-03-04*
