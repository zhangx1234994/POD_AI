# 图编辑扩展画布方案审查记录（2026-05-25）

## 1. 交付包来源

- 交付包：`110_2026-05-25_image_editor_outpaint_mode_gptimage2_handoff_v1.zip`
- 目标：在图编辑器中新增“扩展画布”模式。
- 模型路线：GPT Image 2 图片编辑。

## 2. 初步结论

方向成立，但不能直接照交付包实现。它应作为 `image_edit` 业务下的单图编辑模式，而不是替代现有批量扩图，也不是新增平行业务入口。

当前建议模式名：

- 用户可见：扩展画布
- 接口枚举：`canvas_outpaint`

## 3. 正确点

- 将扩图放进图编辑器，符合“图编辑器是单张图片统一解”的定位。
- 不暴露 LoRA、denoise、cfg、sampler、seed 等模型内部参数。
- 默认保持原图区域不变，外扩区域由模型补全，符合用户直觉。
- 后端先生成目标画布和蒙版，再调用 GPT Image 2，技术路径可落到现有 `image_edit` 编译器。
- 默认一次生成 1 张图，批量处理继续交给批量业务。

## 4. 风险点

1. `输出宽高`、`扩展方向`、`原图位置` 三套控制容易冲突。
   - 建议交互上以画布拖拽和快捷扩展为主，数字参数只作为结果展示和高级输入。

2. 蒙版语义必须固定。
   - OpenAI 图片编辑要求 mask 与图片同尺寸且包含 alpha 通道；透明区域作为可编辑区域的口径必须在代码、文档、测试里写死。

3. “严格保持原图后贴回”可能造成接缝。
   - 这仍是必要兜底，但验收必须增加接缝、断层、颜色不连续检查。

4. GPT Image 2 mask 是提示约束，不是像素级绝对约束。
   - 页面和文档不能承诺 100% 不改原图，只能通过后贴回和验收降低风险。

5. 商品图不是主要优势场景。
   - 交付包已提示商品图可作为反例测试；不要把第一版定位成商品图万能扩图。

6. 现有图编辑器交互空间已经偏紧。
   - 扩展画布不能再增加常驻右侧大面板；必须围绕大画布重排。

## 5. 缺失点

- 缺少“目标画布不能小于原图”的错误码和文档口径。
- 缺少“原图放置位置越界”的错误码和文档口径。
- 缺少“目标尺寸不满足 GPT Image 2 约束”的页面即时校验。
- 缺少不同图像类型的提示词策略：花纹、插画、背景、商品图应有不同提示倾向。
- 缺少自动失败判定项：留白、透明块、灰块、没扩出去、原图被改、结果尺寸不对。
- 缺少与现有 `outpaint` 批量接口的边界说明。

## 6. 实现建议

### 后端

- 复用 `/api/business/image-edit/runs`。
- 新增 `editSkill=canvas_outpaint`。
- 后端编译：
  - 下载或读取原图尺寸。
  - 校验目标宽高、16 倍数、最大边、长短边比例、总像素。
  - 根据 `anchor/placement` 生成目标画布。
  - 原图贴入目标画布。
  - 生成同尺寸 alpha mask：原图区域保护，外扩区域可编辑。
  - 编译扩展画布提示词。
  - 调用现有 `openai_gpt_image_2_edit`。
  - `preserveOriginal=true` 时，模型返回后中台把原图按编译时的位置重新贴回，并将后处理后的图作为业务轻量结果。

### 前端

- 图编辑器新增“小模式”而非大卡片：扩展画布。
- 主路径：
  - 上传主图。
  - 选择快捷扩展方向或拖动画布边缘。
  - 页面直接展示目标画布、原图位置和待补区域。
  - 用户在底部一句话写补充要求。
  - 输出设置折叠为小按钮。
- 参考图面板默认折叠；只有用户明确使用或当前模式需要时展开。
- 结果区不常驻挤压画布，测评端可以作为组件外层能力展示。

### 文档

- `image_edit` 文档新增 `canvas_outpaint`。
- 错误码总表补齐尺寸、位置、目标画布、蒙版生成失败相关错误。
- 交付材料明确：图编辑扩展画布是单图编辑；批量扩图接口仍是另一类业务。

## 7. 本版边界

本版应做：

- `canvas_outpaint` 模式。
- 目标画布和 alpha mask 后端生成。
- 默认严格保持原图。
- 低质量真实模型测试。
- 测评端画布交互可闭环。
- 文档、枚举、错误码和交付说明同步。

本版不做：

- 批量扩图替换。
- ComfyUI 扩图方案重构。
- 多候选图批量生成。
- Photoshop 式多图层编辑器。
- 面向外部客户的短期组件令牌。

- [x] 横向、纵向双边扩展已有前端快捷入口和后端扩展参数。
- [x] 目标尺寸小于原图被拒绝。
- [x] 原图放置位置越界被拒绝。
- [x] 非 16 倍数自动向上取整；超最大边、超比例、超像素限制被拒绝。
- [x] 结果尺寸按目标尺寸提交给 GPT Image 2。
- [x] `preserveOriginal=true` 时业务结果后处理贴回原图区域。
- [ ] 外扩区域无透明、留白、灰块、纯色块。
- [ ] 接缝处无明显断层。
- [ ] 管理端按 runId 能看到中间画布、mask、GPT Image 2 调用和结果回填。
