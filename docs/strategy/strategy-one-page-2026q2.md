# 产品战略一页纸（2026Q2）

## 1. 战略目标

把当前“可跑通的内部系统”升级为“可商用的 AI 生产平台”。

约束：

- 稳定性优先于功能扩张
- 先统一产品与商业框架，再扩端（小程序/移动端）
- 所有新功能必须有明确收入或留存价值

## 2. 北极星指标

- 北极星：`周活跃任务发起用户数（WAU-Task）`

定义：

- 周内至少发起 1 个有效任务（最终状态成功或失败可解释）

## 3. 核心 KPI（Q2）

1. 任务成功可回填率 >= 98%
2. 7 日留存 >= 35%
3. 任务提交到首个结果中位时长 <= 120s
4. 付费转化率 >= 8%
5. 有效错误可解释率 >= 95%

## 4. 用户分层与主路径

1. 业务设计/运营：发任务 -> 看结果 -> 复用模板 -> 导出
2. IT 运维：监控节点 -> 处理异常 -> 修复同步 -> 发布清单
3. 开发接入方：查模型参数 -> 调接口 -> 轮询结果 -> 排错

## 5. 商业化锚点

1. 计费单位：按任务成本核算（模型成本 + 算力时长 + 存储占用）
2. 收费点：高级模型、批量并发、团队协作、API 调用量、存储保留
3. 充值模式：余额包 + 套餐包（企业月结作为后续阶段）

## 6. 身份与权限方向

阶段目标（Q2）：

1. 完成统一登录注册（手机号/邮箱至少一种）
2. 完成角色分层（个人、团队成员、管理员）
3. 完成基础账单与充值闭环

## 7. 体验与信息架构原则

1. 侧边栏收敛到少量高频一级入口
2. 每个页面只保留一个主工作区
3. 状态、错误、结果展示统一语义
4. 给大屏提供“紧凑模式”提升操作空间

## 8. 90 天里程碑

1. M1（第 1-3 周）：战略与 IA 定稿，单一待办池上线
2. M2（第 4-7 周）：认证、充值、账单、状态一致性完成
3. M3（第 8-12 周）：增长机制和移动端 IA 定稿，准备小程序实施

## 9. 不做清单（Q2）

1. 不做大范围新模型盲目接入
2. 不做无计费闭环的新商业功能
3. 不做多套并行文档体系
