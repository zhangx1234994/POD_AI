## 发现问题

1. 测评端结果区存在上一条结果残留
   - 现象：用户变更主图、模式或提示词后，右侧仍可能显示上一条成功结果。
   - 风险：用户可能把历史结果误认为当前参数结果。
   - 本地处理：参数变更后隐藏上一条结果，提示“当前参数已变更，重新提交后展示本次输出”。

2. 测评端提交存在重复创建 run 风险
   - 现象：浏览器网络记录中出现两次相同 `POST /api/evals/runs`，payload 完全一致。
   - 风险：重复扣费、重复排队、历史记录噪音。
   - 本地处理：在 React 状态之外增加同步提交锁，避免按钮禁用状态尚未刷新时重复进入提交逻辑。
   - 后续建议：服务端补 `requestId`/幂等键兜底。

3. 管理端接口证据文案对内部/测评任务偏噪
   - 现象：内部巡检和测评端创建的任务显示“未记录入口调用 / 未匹配到业务入口日志”。
   - 风险：真实合法的内部链路被误读为入口漏打点。
   - 本地处理：对 `eval-web`、`admin-test`、patrol/smoke/internal 渠道显示“内部/测评提交”，说明通常没有外部入口调用日志。

4. 管理端执行节点文案对第三方模型通道偏噪
   - 现象：OpenAI/GPT Image 2 类任务可能显示“未见执行节点”。
   - 风险：被误判为调度节点缺失。
   - 本地处理：无固定 executor 但存在第三方模型供应商/模型信息时，显示“第三方模型通道”。

5. 测评端历史/轮询较重
   - 现象：提交后持续刷新 `with-latest-annotation` 列表，历史区内容较多。
   - 风险：弱网或多用户情况下页面噪音和请求压力增加。
   - 本轮处理：暂记录为后续体验/性能优化项，未在本次改动中改变轮询策略。
