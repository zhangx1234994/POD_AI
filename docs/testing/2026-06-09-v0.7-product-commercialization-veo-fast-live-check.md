## 关键修正

线上第一次真实验证时发现：请求传 `durationSeconds=6` 可以生成视频，但下载后的 MP4 实际仍为 `8.000000s`。结合 KIE Veo 3.1 文档和实测，当前直出视频不应对外承诺 4/6/8 精确可控时长。

已修正为：

- 后端 `ProductCommercializationRequest.durationSeconds` 只接受 `8`
- 测评端视频能力页不再显示可选秒数，改为 `8 秒（Veo 3.1 Fast 当前固定）`
- 接口文档同步说明：长视频后续通过分镜/合成实现
- 视频 prompt 语法修正为 `Create an 8-second...`

负向验证：

- `durationSeconds=6` -> `422`
- 关键信息：`Input should be 8`
