## 当前发现

1. 测评端功能详情页稳定完成加载偏慢。GPT Image 2、ComfyUI、生成图评估、图片打标签详情页完整等待约 15-19 秒，主要原因是进入页面后会拉取较多历史记录和图片资源。首屏能打开，但体验仍偏重，后续应做历史记录分页、图片懒加载或默认只加载最近少量记录。
2. 结构化结果类功能仍沿用生图回填口径。生成图评估、图片打标签在历史记录里会显示“成功无回填 / 无结果”，但这类能力本身输出的是结构化 JSON，不一定有图片。建议改成“结构化结果已完成 / 无图片输出”，避免测试人员误判为异常。
3. GPT Image 2 历史失败记录中仍可看到 `BUSINESS_RUN_GET_FAILED:业务任务结果查询失败，请稍后重试`。已经不是原始数据库大堆栈，但历史记录仍会影响观感；后续项目清理时可归档或修复这些旧记录的展示状态。
