# 周报 · 2026-W11

## 本周主题

- 项目接手准备
- 当前系统真实边界确认
- 并发与路由专项方案整理

## 关键结论

1. 当前真正稳定的主链路是：
   - 账号密码登录
   - 统一能力调用
   - AbilityTask 异步任务
   - OSS 媒资沉淀
   - 管理端配置与测试
2. 钱包、统一身份、通用任务编排、可视化工作流平台等仍属于规划或半落地，不应当成现状。
3. 并发与路由需要按“候选池 + 队列分流 + 单机上限”理解，而不是只看全局线程池。

## 本周对后续仍有价值的事项

### 项目接手

- 真源文档、历史文档、规划文档需要先分层再读。
- 接手时优先核对环境、执行节点、能力目录、错误契约和固定端口。

### 并发与路由

- KIE 与 ComfyUI 的并发约束不能混为一谈。
- ComfyUI 双机承载的前提是能力候选池里真的有两台可互替机器。
- 单机上限、总候选池承载和 queue-aware routing 必须一起看。
