# AI创品业务客户端

这是 AI创品业务客户端，用于验证“批量图处理 -> 图片资产 -> POD 产品样例”的主路径。当前不连接 114，不走 Coze，不复用历史客户端。

## 运行

```bash
cd podi-client-web
npm install
npm run dev -- --port 5180
```

默认连接主站业务 API：

```text
VITE_PODI_API_BASE=http://127.0.0.1:8240
```

本地闭环需要同时启动业务 API：

```bash
python3 ../podi-business-api/server.py --host 127.0.0.1 --port 8240
```

如需业务 API 再代理真实中台能力，在启动业务 API 时配置：

```bash
PODI_MIDPLATFORM_BASE_URL=http://127.0.0.1:8099
PODI_MIDPLATFORM_API_KEY=你的中台业务Key
```

## 当前范围

- 图工具箱：花纹提取、图案裂变、扩图、单图精修、产品样例。
- 任务中心：提交业务任务、保存 runId、轮询 `/api/business/runs/get`。
- 图片资产：结果图沉淀、精选、继续处理、做产品。
- 产品样例：从资产选择图案，调用产品设计业务接口。
- 点数与券、分享增长、运营后台：先表达 P0/P1 运营规则和状态，不做真实支付/结算。

## 重要边界

- 客户端负责用户动线和页面交互。
- 主站业务 API 负责账号、素材、任务、订单、钱包和多站点业务隔离。
- 中台负责能力、路由、执行节点、结果、质量和成本证据。
- POD 产品化使用已有可生产版型，不做从零商品结构设计。
- P0 只承诺产品样例和数字素材包，不承诺完整实物履约。
