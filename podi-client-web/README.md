# 洗图宝业务客户端

这是新的业务客户端本地雏形，用于验证“批量图处理 -> 图片资产 -> POD 产品样例”的主路径。当前不连接 114，不走 Coze，不复用历史客户端。

## 运行

```bash
cd podi-client-web
npm install
npm run dev -- --port 5180
```

默认连接：

```text
VITE_PODI_API_BASE=http://127.0.0.1:8099
```

如需调用真实中台业务接口，创建本地 `.env.local`：

```bash
VITE_PODI_API_BASE=http://127.0.0.1:8099
VITE_PODI_API_KEY=你的业务Key
```

## 当前范围

- 图工具箱：花纹提取、图案裂变、扩图、单图精修、产品样例。
- 任务中心：提交业务任务、保存 runId、轮询 `/api/business/runs/get`。
- 图片资产：结果图沉淀、精选、继续处理、做产品。
- 产品样例：从资产选择图案，调用产品设计业务接口。
- 点数与券、分享增长、运营后台：先表达 P0/P1 运营规则和状态，不做真实支付/结算。

## 重要边界

- 客户端负责业务组装和用户动线。
- 中台负责能力、路由、任务、结果、质量和成本证据。
- POD 产品化使用已有可生产版型，不做从零商品结构设计。
- P0 只承诺产品样例和数字素材包，不承诺完整实物履约。
